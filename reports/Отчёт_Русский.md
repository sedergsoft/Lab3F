# Отчёт по лабораторной работе № 3 — MiniList<T>

## Цель работы
Реализовать обобщённую коллекцию на основе односвязного списка на языке C# и обеспечить перебор её элементов с помощью стандартного интерфейса перечисления .NET.

## Теоретические сведения
Односвязный список состоит из узлов. Каждый узел хранит значение и ссылку на следующий узел. Элементы списка не обязаны располагаться в непрерывной области памяти. Класс `MiniList<T>` хранит ссылки на первый и последний узлы, а также количество элементов.

## Реализация
- Метод `Append(T item)` добавляет элемент в конец списка и возвращает его индекс, начиная с нуля.
- Свойство `Count` возвращает количество элементов.
- Интерфейс `IEnumerable<T>` позволяет использовать цикл `foreach`.
- Итератор последовательно проходит по узлам в порядке добавления.
- Приложение Windows Forms позволяет создать список, добавить элементы `CheckBox` и отдельно подсчитать визуальные элементы и объекты коллекции.

## Рекомендуемые ручные тесты
1. Запустить приложение и выбрать **Создать список**.
2. Несколько раз выбрать **Добавить элемент**.
3. Выбрать **Перебор кнопок** и проверить количество визуальных элементов.
4. Выбрать **Перебор объектов** и проверить количество элементов коллекции.
5. Создать новый список и убедиться, что он пуст.
6. Попробовать добавить элемент до создания списка и проверить, что приложение сообщает о необходимости сначала создать список.

## Вывод
В ходе работы демонстрируется реализация обобщённой структуры данных на основе связных узлов и интеграция перечислителя со стандартными средствами C#. Графический интерфейс показывает связь между визуальными элементами и объектами коллекции.
